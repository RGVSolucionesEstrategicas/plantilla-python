# GIT Cheat Sheet

Comandos básicos de GIT

### Branches

##### Ver en que branch estoy

```bash
git branch
```

##### Cambiar de branch

```bash
git checkout <branch>
```

##### Crear una branch nueva

```bash
git checkout -b <branch>
```

### Flujo de trabajo básico

##### Agregar cambios al staging area

```bash
git add .
```

##### Hacer commit de los cambios

```bash
git commit -m "Mensaje del commit"
```

##### Hacer push de los cambios al repositorio remoto

```bash
git push origin <branch>
```

##### Hacer pull de los cambios del repositorio remoto

```bash
git pull origin <branch>
```
